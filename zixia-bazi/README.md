# 子夏八字

「子夏八字」是一套可公开安装的 Codex Skill，自带离线四柱排盘程序。它先根据出生信息计算命盘，再依据五行、十神、大运和流年进行结构化解读。

## 欢迎使用

调用「子夏八字」后，系统会主动提示：

> 欢迎使用「子夏八字」。为了准确排盘，请提供以下资料：  
> 1. 姓名、昵称或代称（选填，不填写也可以）  
> 2. 出生日期  
> 3. 阳历或农历；农历请注明是否闰月  
> 4. 出生时间（尽量精确到分钟；不确定可写“几点左右”）  
> 5. 性别  
> 6. 出生城市或地区  
> 例如：小夏，女，1990年1月1日，阳历，晚上20:30，北京。  
> 如果时间接近两个时辰的交界，我可以分别生成前后两套候选命盘进行比较。

## 主要功能

- 四柱、藏干、五行和十神排盘
- 日主强弱与命局结构分析
- 性格特点、职业方向与财富方式
- 感情、家庭及现实关系建议
- 十年大运、近期流年与交运提醒
- 出生时间接近时辰交界时的双盘比较
- 约 30% 命理依据、70% 现实表达的生命蓝图报告

## 安装

将下面的命令交给 Codex 执行：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo zixia-han/zixia-skills \
  --path zixia-bazi
```

也可以直接把本 Skill 的 GitHub 链接发给 Codex，并说：

> 请帮我安装并使用这个 Skill。

## 如何调用

安装完成后，新建一个 Codex 对话并输入：

> 请使用「子夏八字」为我排盘。

Skill 会主动收集缺少的必要资料。建议一次提供：

1. 姓名、昵称或代称（选填；不填写也可以）
2. 出生日期
3. 阳历或农历；农历需注明是否闰月
4. 出生时间，尽量精确到分钟
5. 性别
6. 出生城市或地区

示例：

> 小夏，女，1990年1月1日，阳历，晚上20:30，北京。请使用子夏八字排盘。

姓名只用于报告称呼，不参与四柱、五行、十神、大运或流年的计算。不要求身份证姓名、身份证号码或曾用名。

## 出生时间不确定

如果只记得“几点左右”，并且时间接近两个时辰的交界，请如实说明。子夏八字可以分别生成交界前后的两套候选盘，比较时柱、性格表达、职业方式、关系结构和关键年份。

出生证明、医院记录或家人的可靠记忆，优先于性格描述和事件匹配。双盘比较只能用于辅助校时，不声称反推出精确分钟。

## 使用边界

八字属于传统术数与文化分析工具，可用于认识自身结构、理解阶段趋势并获得一般性的指导和建议。

如果现实中已经出现健康、法律、财务、心理或其他重要问题，应当寻找医生、律师、持牌财务人员、心理专业人士等相应的专业帮助。命理分析不能替代这些专业判断，也不应被表述为确定事实或结果保证。
