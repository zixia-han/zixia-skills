## 1. 强弱与格局

按证据判断，不用五行字数或百分比替代旺衰：

- 令：日主是否得月令。
- 地：日主是否通根，根在本气、中气还是余气。
- 势：印比与食伤财官杀的整体配置。
- 调候：季节的寒、暖、燥、湿。
- 流通：是否连续相生，是否两行交战或一行堵塞。

特殊从格从严。分别说明扶抑、格局、调候等取用角度；流派不一致时保留差异。“缺某五行”不等于机械补该五行。

## 2. 输出模式

### 客户生命蓝图模式（默认）

- 保留约 30% 的五行、十神、格局与组合术语，用于交代判断依据；约 70% 使用客户能直接理解的现实语言。
- 开头展示排盘口径和四柱，随后用一小段完成强弱、关键五行及主要十神判断，不展开长篇教学。
- 依次输出：一句话定位、核心能力、主要短板、唯一职业方向、正偏财、家庭关系、感情关系、助力与庇护、大运流年、行动建议。
- 职业给一个主方向，并可列出若干适合的行业与角色。
- 大运必须列出准确起运日期和完整大运表；阶段主题使用大白话，明确当前大运和下一大运。默认只重点解释当前流年及后两年。
- 把不确定性写在对应结论或结尾，不在每句话反复使用“可能、也许、容易”。
- 不主动加入历史校验题，除非用户正在测试 Skill、校时或核验准确度。

内部测试模式与盲测隔离模式见 [testing-rules.md](testing-rules.md)。

## 3. 职业方向

十神必须结合得令、透干、通根和受制再解释：

- 比肩、劫财：自主、同辈、竞争、边界。
- 食神、伤官：输出、表达、创造、教学、质疑规则。
- 正财、偏财：资源、交易、价值实现、现实经营。
- 正官、七杀：规范、责任、压力、权力和行动约束。
- 正印、偏印：学习、支持、理论、研究和非标准知识。

性格同时给优势、过度使用时的短板和改善方法。事业侧重工作方式、角色和价值路径，不只列行业；财运不预测具体收益；关系不作必婚必离断言；健康不作诊断。

职业部分回答：**主方向是什么，适合哪些行业和角色。**

- 先给主方向，再列 3—6 个适合的行业或角色。
- 用 2—4 个短段说明这个方向实际解决什么问题、通常包含哪些工作内容，以及盘面依据。内容应充实但不扩展成多个职业。
- 证据不足时使用更宽但仍单一的职业功能，例如“项目运营管理”，不要用多个方向回避判断。

## 4. 正财、偏财与助力

财运固定拆为五部分：

1. **正财**：稳定工资、长期客户、持续经营与可预测收入；说明是否透干、得令、通根及日主能否承载。
2. **偏财**：项目、合作、资源撮合、副业与机会性收入；说明机会来源和主要风险。
3. **财富承载**：结合身强弱、比劫、印星与财星判断“机会多不多”和“留不留得住”是两件事。
4. **收入结构**：明确适合以正财为主、偏财为主，或“稳定现金流＋少量项目增量”。
5. **财务风险**：只给一般性的节奏、合作、杠杆和边界提示，不预测具体金额，不代替专业理财意见。

财运判断采用固定顺序：

1. 先判断日主是否足以任财，再判断财星带来的机会。
2. 检查原局财星是否已经过旺，流年或大运是否继续叠加。
3. 检查财星是否引动刑冲合害，或进一步生官杀形成合同、规则、诉讼、职位责任与处罚压力。
4. 将结果拆成四项：机会、承接、留存、代价。
5. 身弱财旺且再次遇强财时，不把“财旺”写成“财运旺”；优先考虑收入不及支出、项目拖累、责任扩大、合作纠纷或资金周转压力。

不得仅凭八字断言必有官司或必定败诉。出现财官叠加、刑冲显著等结构时，只提示合同、证据、合规、利益分配和法律程序风险，并建议咨询专业人士。

设置“助力与庇护”栏目：

- 优先看正偏印、天乙等已由可靠工具计算的贵人信息，以及有明确生克组合依据的支持结构。
- 将印星解释为学习能力、师长、专业证照、制度、平台和恢复力；将比劫解释为同伴、团队与合作支持；其他贵人结构也要落到现实载体。
- 若脚本没有输出某项神煞，不凭记忆补算。可仅基于印星、比劫及已计算组合分析现实支持来源。
- 使用“更容易从……获得支持”“关键时刻可借助……”等表述，不使用“必有贵人”“受神灵保护”“一定逢凶化吉”。

## 5. 家庭与感情

家庭与感情分开解释，不设置“原生家庭”和“成年后的家庭”两个重复栏目：

1. **家庭关系**：从全局结构说明本人现在容易承担的家庭角色，并写出两类具体互动模式，例如“别人有事先来找她处理”“先答应、事后觉得负担过重”。说明金钱、时间或责任如何影响相处，再给出边界建议。避免只写“重视家庭、责任感强”。
2. **感情关系**：说明看重的伴侣品质、容易被何种互动吸引、主要冲突模式与表达需求。
3. **改善方法**：至少给出两条可执行建议，如明确分工、共同预算、重大决定冷静期、直接表达需求或保留个人空间。

成年人直接写“家庭关系”，不再区分“原生家庭”和“成年后的家庭”。未成年人的报告按年龄写亲子互动和未来关系能力。不用“必克父母、婚姻必败、一定离婚”等断语。

## 6. 大运流年

先引用脚本返回的 `start_solar`、方向和大运干支。解释顺序：原局是底色，大运是十年环境，流年是触发。未来按机会、压力、建议三段式表达，不保证事件发生。

客户版的流年用统一格式：

- 主题：这一年的主要人生课题。
- 机会：适合推进什么。
- 压力：最需防范什么。
- 建议：给出 1—3 条具体行动。

默认详写当前流年和后两年；用户明确要求更多年份时再展开。

大运段落开头必须直接回答：

- 几岁或哪一天起运；
- 现在处于哪一步大运，起止年份是什么；
- 下一步大运是什么，从哪一年开始；
- 当前公历年是什么流年干支。

大运表中的阶段主题必须翻译成现实处境，禁止只写“学习探索、能力输出、财富扩张、结构重组”等抽象标签。写成完整的大白话，例如“这十年开始独立做决定，也会逐步进入社会”“这十年挣钱机会增加，但工作和关系也容易重新调整”。

大运表固定采用三列表头：**大运｜年份｜运势提醒**。报告中不得出现“用大白话解释”“大白话说明”等内部写作提示。

### 大运交接点

大运不是统一在公历元旦切换。以脚本返回的首次 `start_solar` 为锚点，每步大运按十年顺延，写出当前运与下一运的具体交接日期。

固定检查三段：

1. **交运前一年**：旧大运问题收尾，原有结构是否已经出现松动。
2. **交运当年**：先按具体日期区分交接前后，再看当年流年如何同时触发旧问题和新主题。
3. **交运后一年**：新大运的现实主题是否开始稳定显现。

可以将这三年称为“交运适应窗口”，但不要声称旧运和新运以固定比例混合，也不要把所有变化都归因于交运。

### 冲突年份的判断顺序

按以下顺序分析，不因单个冲刑字样夸大结论：

1. 原局本来承载什么矛盾或资源；
2. 大运增加了哪种十神和五行力量；
3. 流年是否补齐三会、三合、三刑或明显成局；
4. 是否直接触发日支、月支、时支等关键位置；
5. 再检查刑、冲、合、害、破、伏吟；
6. 最后结合日主能否承载，将结果落到机会、责任、留存和代价。

客户版可用一行结构说明：

> 原局已经存在___，这步大运把___放大，当年又用___触发，所以现实中更容易集中表现为___。

### 理论的现实翻译

| 命理词 | 现实语言 | 不可机械理解为 |
|---|---|---|
| 冲 | 原有安排被推动、替换、分开或迁移 | 一定有灾 |
| 刑 | 问题反复、内部摩擦、隐性成本和持续消耗 | 一定受伤或坐牢 |
| 害 | 表面仍在合作，实际配合失灵、利益暗耗 | 一定被人陷害 |
| 破 | 原有结构松动、计划被拆开后重组 | 一定破产 |
| 合 | 绑定、合作、牵连、被某件事占住 | 一定是好事或婚恋 |
| 三会/三合成局 | 某种五行和十神力量在该阶段高度集中 | 一定大吉或大凶 |
| 伏吟 | 同类主题重复出现、感受加重或进展反复 | 一定发生同一件事 |

翻译后继续结合十神：财星集中时看收入、成本、资金和现实责任；官杀集中时看制度、合同、职位、处罚和压力；印星集中时看学习、资质、支持和恢复；食伤集中时看表达、产品、业务输出及与规则的摩擦；比劫集中时看自主、同行竞争、合作分配和边界。

过去大运以表格概述即可。从当前大运开始，每一步未来大运使用固定结构：

1. **十神依据**：说明运干、运支及其与原局的关键关系。
2. **阶段任务**：用一句话回答这十年主要解决什么问题。
3. **阶段机会**：说明适合推进的现实事项。
4. **阶段压力**：说明主要风险和边界。
5. **建议**：给出简洁的生活与决策建议，不再重复岗位、能力、收入升级或职业清单。

职业随大运变化时，写“同一核心能力在不同阶段的角色升级”，避免把每一步运写成毫无关联的换行业清单。

## 7. 双盘校时

共同由年月日决定的内容只写一次。至少比较：

| 维度 | 候选A | 候选B | 区分度 |
|---|---|---|---|
| 时柱与藏干 |  |  | 高 |
| 五行流通 |  |  | 中/高 |
| 主要十神 |  |  | 高 |
| 刑冲合害 |  |  | 高 |
| 大运起始 |  |  | 依计算结果 |
| 长期职业方式 |  |  | 中 |
| 预先选定历史年份 |  |  | 高 |

最后给候选优先级和证据强弱，不把心理认同当作出生时间证明。

校时报告必须把年份分成两类：

- **共同风险年**：由两盘共有的年月日、大运和流年形成，用于验证整体命盘逻辑，不用于判定寅时或卯时。
- **时辰区分年**：流年或大运直接触发候选时柱，才用于比较哪套盘更受支持。

例如某年由共有日支、大运支和流年支构成三会局，即使事件非常明显，也只能算两盘共同命中；不能因为事件重大就偏向任一时辰。

### 交界时间的主动提示

出生时间在时辰边界前后约 30 分钟，或用户使用“左右、前后、不确定是几点前还是几点后”等表达时，主动告诉用户可以：

1. 分别生成交界前和交界后的两套盘；
2. 对比两盘的时柱、十神、组合、性格表达、职业方式、关系结构和高区分度年份；
3. 用 3—5 个时间明确、影响较大的历史事件进行回溯验证；
4. 给出哪一盘“更受支持”的暂定结论，用于校正更接近真实的出生时辰。

优先询问能够明确到年份的事件，如升学或退学、首次就业或明显转岗、结婚分手、跨城市搬迁、手术住院、诉讼以及明显财务变化。不要只用模糊性格印象定盘，不用疫情等全民事件作为强证据，不声称能精确反推到某一分钟。

客户提示语可写成：

> 您的时间接近时辰交界，我可以把交界前、交界后的两套盘都整理出来。之后再对照您过去几次时间明确、影响较大的经历，判断哪一套得到的支持更多，从而校正出更接近真实的出生时辰。

## 9. 重大经营与组织失稳风险

用户询问事业低谷、公司经营、官司、破产或重大转折，或正在验证 Skill 时，增加专项扫描。目标不是猜中“公司倒闭”四个字，而是在不知道现实结果时，提前识别经营系统、任职平台、合作关系或现金流容易集中失稳的年份。

### 9.1 先冻结命盘判断

在读取用户的现实结果前，先记录目标年份或目标大运的原始判断，包括风险等级、主要风险类型和盘面依据。若用户已经说出结果，只能将后续内容标为“已知结果后的命理复盘”，用于提炼通用规则，不能算作预测命中。

### 9.2 三层证据链

按“原局底色→大运放大→流年触发”逐层判断：

1. **原局底色**：先看日主承载、财官强弱、印比是否能支持，以及原局是否已有财生官杀、财多身弱、食伤犯官、比劫争财或关键宫位反复受制等结构。
2. **大运放大**：判断十年环境是否继续增加原局已偏重的财、官杀或竞争力量，是否削弱印比支持，或使合同、制度、资金、合伙方面的矛盾成为阶段主线。
3. **流年触发**：优先检查流年是否补齐三会、三合、三刑等集中结构，是否直接触发月支、日支、时支，再看刑冲合害破、伏吟及天干财官食伤的叠加。

不能用单个冲、刑、害、财星或官杀判定重大问题。三层同时指向同一现实领域时，才列为高风险年；只有一层明显时，列为普通波动年。

### 9.3 风险类型映射

把组合翻译成有限且有优先级的现实风险：

| 主要结构 | 优先检查的现实领域 |
|---|---|
| 身弱而财星再次集中 | 现金流、成本、债务、回款、项目规模超过承载 |
| 财生官杀且官杀成势 | 合同、税务、监管、诉讼程序、职位责任与处罚 |
| 比劫争财或合伙位受冲害 | 股权、分账、合作方、客户流失与利益分配 |
| 食伤与官杀强烈交战 | 决策与规则冲突、产品承诺、证据表达、对外争议 |
| 印星受损且财官压身 | 专业支持不足、资质手续、信息判断和恢复能力下降 |
| 月支或事业相关结构被成局触发 | 任职平台、部门、商业模式、供应链或组织架构调整 |

“公司倒闭”只是上述风险在特定身份和现实条件下的一种结果。同一命理结构也可能表现为所在单位裁撤、项目终止、被迫转岗、合伙拆分、严重亏损或诉讼压力。若不知道当事人是否创业，统一写“经营或工作平台存在明显失稳风险”。

### 9.4 风险分级与输出

- **普通波动**：只有单一触发，承载和支持尚可。提示变化，不渲染危机。
- **重点防守**：原局弱点被大运或流年明显放大，两个层次指向同一领域。列出首要风险和检查动作。
- **高风险窗口**：原局、大运、流年三层成链，且出现成局或多个关键位置同步触发。明确写“这一年不宜用扩张解决压力，应优先保现金流、合同证据和组织边界”，但仍不写必然破产、倒闭或败诉。

客户版最多给出三个优先风险类型，并按强弱排序；同时给出三项现实检查，例如：

1. 做未来 6—12 个月现金流压力测试，区分账面收入与实际回款；
2. 复核合同、税务、授权、担保、股权和关键证据链；
3. 为核心客户、供应商、合伙人或任职平台准备替代方案。

### 9.5 回溯验证

扫描一个完整大运时，先逐年使用同一套标准，再选出 2—4 个风险最集中的年份，不可只挑用户已经披露的年份。收到反馈后分别记录：年份是否对应、事件领域是否对应、严重程度是否对应。重大事件若两套候选时辰共有，只能验证共同年月日和大运逻辑，不用于校时。

匿名示例：原局财重、承载偏紧；大运增加官杀和规则压力；某流年再令财星叠加，并补齐官杀会局，同时出现刑害。可在未知现实结果时把该年列为“经营或工作平台高风险窗口”，优先检查现金流、合同合规、合作关系和组织结构；但不得预写成“公司一定倒闭”。
